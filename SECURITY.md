# Security Policy

## Supported versions

Security fixes are provided for the latest `0.1.x` release and the current `main` branch.

| Version | Supported |
| --- | --- |
| `0.1.x` | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Do not report security vulnerabilities in a public issue.

Use GitHub private vulnerability reporting when it is available. Alternatively, email **ayush33156@gmail.com** with the subject `Mirai security report`.

Include the affected version, impact, reproduction steps, and any suggested mitigation. Use synthetic test data and do not attach real uploaded images, prompts, credentials, or diagnostics.

Please allow time to investigate and coordinate a fix before public disclosure.
